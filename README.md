# Priyanka — Portfolio (Issue Nº 01)

A personal portfolio website designed like a **fashion magazine**: editorial serif typography, full-bleed photography, a pinned horizontal "lookbook" of projects, and smooth scroll-driven animation.

## 🔗 Visit the site

**[https://priyanka2771.github.io/Personal-Portfolio-Website/](https://priyanka2771.github.io/Personal-Portfolio-Website/)**

## The "issue" — page by page

| Page | Section | What's there |
| ---- | ------- | ------------ |
| Cover | Home | Full-bleed cover photo, giant masthead, cover lines |
| 02 | Editor's Letter | About me, pinned photo, skills index, count-up stats |
| 03 | Features | Services, with a full-bleed feature photo |
| 04 | The Lookbook | Projects in a pinned, horizontally scrolling gallery |
| 05 | Letters | Contact form (opens your mail app), copy-email button |

## Features

- Preloader countdown and animated page transitions
- Scroll-linked parallax, word-by-word text reveals and image "curtain" reveals with blur-up loading
- Pinned horizontal project gallery
- Fixed side rail with page counter, scroll-progress bar and back-to-top
- Fullscreen table-of-contents menu
- Light / dark ("Day / Night") theme, remembered between visits
- Custom cursor on desktop; respects `prefers-reduced-motion`
- Responsive and mobile-friendly

## Built with

React 18 · Vite 5 · Tailwind CSS 3 · Framer Motion · deployed with GitHub Pages (`gh-pages`)

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173/Personal-Portfolio-Website/`).

| Script | What it does |
| ------ | ------------ |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Preview the production build |
| `npm run deploy` | Build and publish `dist/` to GitHub Pages |

## Customising

All content lives in [`src/data.js`](src/data.js) — name, email, GitHub link, images, skills, services and projects. Edit it and the site updates.
